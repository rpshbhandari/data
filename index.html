Nepal's tax and market rates, as JSON

A free API for income tax slabs, TDS and VAT rates, depreciation pools, NEPSE charges and the Bikram Sambat calendar. Every file says when its figures were last checked and where they come from, and the calculators on tools.rupeshbhandari.com.np read these same files. Pick an endpoint below and press Send request to see the live response.

BASE URL https://data.rupeshbhandari.com.np/v1/
  • GET only
  • JSON
  • No key or sign-up
  • CORS open: call it from a browser
  • Past years never change
OVERVIEW Conventions ENDPOINTS

Conventions

  • Every file has dataset, updated (the date its figures were last checked against the source) and sources (a list of { "title", "url" }; url is optional).
  • Rates are percentages: 13 means 13%, and 0.015 means 0.015%.
  • Amounts are whole rupees (NPR). An upper bound of null means the slab has no upper limit.
  • Shares with no exact decimal are fractions in a string, such as "1/3".
  • Dates are AD, as YYYY-MM-DD. Fiscal-year files also give the start of the year in Bikram Sambat: "starts": { "bs": "2083-04-01", "ad": "2026-07-17" }.
  • Each fiscal year is its own file and is never changed afterwards except to fix a mistake, so a calculation for a past year keeps working. A change that would break existing readers goes in /v2/.
  • Responses can be cached for up to 10 minutes. Any website can fetch the files: they are sent with Access-Control-Allow-Origin: *.
  • Python's built-in urllib is turned away unless it sends its own User-Agent header, as in the Python examples below. Other clients work as they are.

Calendar feeds

Two calendar feeds, built from the Bikram Sambat calendar, put the BS date on every day in Google Calendar, Apple Calendar or Outlook. Subscribe once and your calendar app keeps them up to date.

FeedAddressEach day reads
Nepalihttps://data.rupeshbhandari.com.np/calendar/nepali.icsकात्तिक ५; the first of each month adds the year, कात्तिक १, २०८३.
Englishhttps://data.rupeshbhandari.com.np/calendar/english.icsKartik 5; the first of each month adds the year, Kartik 1, 2083.

Subscribe

  • Google Calendar: in the left column, Other calendars → + → From URL, and paste an address above.
  • Apple Calendar (Mac, iPhone, iPad): open the Nepali feed or the English feed and confirm.
  • Outlook: Add calendar → Subscribe from web, and paste an address above.

What's in them

  • One all-day event per day, marked free so it never blocks your time. All-day dates don't shift for people outside Nepal.
  • The event's description gives the weekday and full date, such as बिहीबार, ५ कात्तिक २०८३ or Thursday, Kartik 5, 2083 BS.
  • The feeds start from the year before the current year and run to the end of the calendar file. Days in "projected" years say so in their description, since those dates can still change.
  • When a date is corrected, the event changes in place. Calendar apps refresh subscribed feeds every 12 to 24 hours.

Errors

An address with no file behind it, such as a fiscal year that isn't published yet, returns 404 with GitHub Pages' HTML error page rather than JSON. Check res.ok (or the status code) before parsing, and use index.json to see which files exist.
