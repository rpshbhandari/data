Nepal's tax and market rates, as JSON

Income tax slabs, TDS and VAT rates, depreciation pools and NEPSE charges as plain files. Each file says when it was last checked and where its figures come from, and the calculators on tools.rupeshbhandari.com.np read these same files. Free to use, with no key or sign-up.

Using a file

const url = "https://data.rupeshbhandari.com.np/v1/tax/income/2083-84.json";
const { slabs } = await fetch(url).then((r) => r.json());
// slabs.individual → [{ from: 0, to: 1000000, rate: 1, … }, …]

Rates are percentages (13 means 13%), amounts are in rupees, and a slab with "to": null has no upper limit. v1/index.json lists every file with the date it was last checked.

Past years stay published: a new fiscal year adds a new file and never changes last year's. Figures are copied from the sources named in each file. Check them against the Inland Revenue Department, SEBON or NEPSE before relying on them; this is not tax or investment advice.
